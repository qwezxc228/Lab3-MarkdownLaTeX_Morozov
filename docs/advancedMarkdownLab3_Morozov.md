## Alert-блок

> [!TIP]
> Совет по использованию: Для экранирования специальных символов в Markdown используйте обратный слэш `\`. Например, чтобы написать `*курсив*` без форматирования, напишите `\*курсив\*`.

---

## Escape-символы

- Заголовок без форматирования: \# Это не заголовок
- Звёздочка как текст: \*Просто звёздочка\*
- Нижнее подчёркивание: \_не курсив\_

## HTML в Markdown

<p style="background-color: #f8f9fa; padding: 15px; border-radius: 5px; border-left: 4px solid #007bff;">
Этот параграф оформлен с помощью <strong>HTML-тега</strong> внутри Markdown-документа. Мы можем задавать цвета, отступы и рамки, которые недоступны в чистом Markdown.
</p>
