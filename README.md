# Лабораторная работа №3: Работа с Markdown и LaTeX

## Краткое описание
Данный проект создан в рамках выполнения лабораторной работы №3. Все изменения фиксировались с помощью системы контроля версий Git.

## Форматирование текста

В Markdown можно выделять текст разными способами:
- **Полужирный текст**
- *Курсив*
- ~~Зачеркнутый текст~~
- `Моноширный текст` (inline-код)

---

## Списки

**Маркированный список:**
- Пункт 1
- Пункт 2

**Нумерованный список:**
1. Первый шаг
2. Второй шаг

**Вложенный список:**
1. Основной пункт
   - Вложенный пункт
   - Еще один вложенный пункт
2. Второй основной пункт
